# Komentář k zákonu č. 383/2012 Sb., o podmínkách obchodování s povolenkami na emise skleníkových plynů

Otevřený komentář k zákonu o podmínkách obchodování s povolenkami na emise skleníkových plynů — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; povolení k emisím a k dodávání paliv, obchodování s povolenkami, rejstřík a jeho správce, kompenzace, vykazování a ověřování emisí, přestupky a výkon státní správy.

Konsolidované znění: dokument e-Sbírky `SB-2012-00383_2026-01-01`.
